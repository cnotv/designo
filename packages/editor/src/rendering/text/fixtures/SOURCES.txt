Test-only fonts, never shipped: the editor and the screenshot tool load their fonts from the
Fontsource API at run time. These let the tests shape and draw real files with no network. Each is
an OFL 1.1 font; the licence text sits beside it.

Inter-Regular.subset.ttf
  Inter 4.1 Regular, from the rsms/inter release v4.1 (extras/ttf/Inter-Regular.ttf).
  Licence: OFL-Inter.txt

NotoSansArabic-Regular.subset.ttf
NotoSansHebrew-Regular.subset.ttf
NotoSansDevanagari-Regular.subset.ttf
  Noto Sans Arabic, Hebrew and Devanagari, from the variable fonts in google/fonts (ofl/notosans*),
  instantiated at weight 400 and width 100.
  Licences: OFL-NotoSansArabic.txt, OFL-NotoSansHebrew.txt, OFL-NotoSansDevanagari.txt

All four were reduced with fonttools (pyftsubset --no-hinting --desubroutinize) to the code points
listed in fixtureFontCatalog.ts, keeping the layout features shaping needs.

NotoSans-Latin.fixture.ttf
  Noto Sans Regular from the variable font in google/fonts (ofl/notosans), instantiated at weight
  400, reduced with pyftsubset to Basic Latin and U+FB01. Inter has no fi ligature and the ligature
  test needs a font that does. Licence: OFL-NotoSans.txt
